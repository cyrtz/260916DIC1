# DIC 1 - Retro RPS Arcade

這是一個結合「個人檔案」與「猜拳遊戲」的互動式網頁應用程式，專為課堂練習（Do in class）所設計。採用了充滿復古街機 (Retro Arcade) 感的視覺風格，包含 CRT 螢幕掃描線特效與復古像素字體。

## 專案功能 (Features)

### 1. 玩家個人檔案 (Profile)
- **個人資訊**：顯示玩家姓名 (邱允柔) 及預設狀態資訊。
- **大頭貼上傳**：支援透過 `FileReader` 在本地端上傳自訂大頭照，並自動保存至瀏覽器的 `localStorage` 中，即使重新整理網頁也不會遺失。
- **即時時鐘 (Live Clock)**：畫面上方即時顯示目前的時分秒。

### 2. 猜拳對戰 (Game Modes)
- **1P (VS COM) 單人模式**：
  - 玩家點擊介面上的「石頭/布/剪刀」按鈕，與電腦進行隨機猜拳對戰。
- **2P (LOCAL) 雙人模式**：
  - 隱藏滑鼠操作按鈕，改為支援鍵盤盲按，方便兩人在同一台電腦上對戰。
  - **Player 1** 使用：`A` (石頭)、`S` (布)、`D` (剪刀)
  - **Player 2** 使用：`J` (石頭)、`K` (布)、`L` (剪刀)
  - 雙方均完成輸入後（顯示 READY），系統會同時揭曉兩人的選擇並判定勝負。

## 技術堆疊 (Tech Stack)
- **HTML5**：語意化結構設計。
- **CSS3**：使用 CSS Variables 進行主題顏色管理，並手寫 CRT 螢幕掃描線特效 (Scanlines) 及按鈕微動畫。
- **Vanilla JavaScript**：處理遊戲邏輯、DOM 操作、事件監聽與本地端資料儲存 (`localStorage`)，無依賴任何外部框架。

## 如何執行 (How to Run)
1. 下載或 Clone 此專案。
2. 直接點擊開啟專案目錄下的 `index.html`，即可在任何現代瀏覽器中執行與遊玩，無須啟動任何伺服器。
